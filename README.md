# HDMCM 2026 — Problem B: 医药冷链物流运输优化

本项目为数学建模竞赛（HDMCM 2026）B题的完整解答，围绕医药冷链物流的运输成本核算、拼车路线优化和派车单合理性评估三个递进问题展开建模与求解。

## 问题与模型

### 问题1 — 运输成本核算
从南通市崇川区仓库出发的冷链药品排货信息，计算运输总费用。

- 区域差异化道路绕行系数 β（东1.25 / 中1.40 / 西1.60）
- 往返运输 + 回程空载油耗系数（0.75）
- 固定成本区分工作天（280天）与日历天（365天）
- 车辆折旧按4年直线摊销
- **结果**：294趟运输、43个城市、总费用 **3,846,906.89 元**

### 问题2 — 拼车路线优化
在问题1基础上，通过 Clarke-Wright 节约算法进行拼车优化。

- 方向约束（方位角偏离 ≤ 90°）+ 距离约束（城市间距 ≤ 500 km）
- 托盘容量约束（7.6M: 11托, 9.6M: 14托）+ 组内跨度约束（≤ 120°）
- 支持跨周合并 + TSP路线排序
- 72组参数网格搜索选择最优超参
- **结果**：路线从294条减至127条（-56.8%），成本降至 **1,706,894.88 元**，节约率 **55.63%**

### 问题3 — 派车单评估与优化
评估54个仓库的派车合理性，并给出优化方案。

- 六维指标体系：配送密度（分层市内/干线）、路线合并潜力、时效达标率、线路集中度、冷链合规率、装载饱和度
- 熵权法客观赋权 + 行业基准绝对评分
- 三层递进优化：TSP排序 → 同城同日合并 → 车型匹配 + 冷链强制
- **结果**：系统综合得分 **50.0/100**（需改进），23个仓库冷链合规率 < 50%；周度成本从1,135.3万降至717.5万（-36.8%）

## 运行方式

```bash
# 问题1：运输成本核算
python3 first.py

# 问题2：拼车优化（含网格搜索可选）
python3 second.py           # 默认参数
python3 second.py --grid    # 参数网格搜索

# 问题3：派车评估与优化
python3 third.py

# 生成论文图表（8张）
python3 visualize.py

# 编译论文
cd "final essay"
xelatex main.tex && xelatex main.tex
# 清理辅助文件
rm -f main.aux main.log main.out main.toc main.synctex.gz main.fls main.fdb_latexmk
```

## 关键技术

| 技术 | 用途 | 所在文件 |
|------|------|---------|
| Haversine 球面距离 | 城市间直线距离 | `utils.py` |
| 区域道路绕行系数 β | 直线距→道路距转换 | `config.py` |
| Clarke-Wright 节约算法 | 拼车路线合并 | `second.py`, `third.py` |
| 2-opt 局部搜索 | TSP路径优化 | `utils.py` (`tsp_order`) |
| 熵权法客观赋权 | 六维指标权重 | `third.py` |
| TOPSIS 辅助排名 | 仓库相对排序 | `third.py` |
| 参数网格搜索 | CW算法超参选择 | `second.py` (`grid_search`) |
